# Bureau d'Analyse Terrestre - Partie 1

Analyse des relevés de la sonde Klaxo-3 (données UFO Reports / NUFORC).

## Lancer

```
python analyse.py
```

Le script télécharge les données si besoin (`releves_klaxo3.csv`, non
versionné) et rejoue toutes les phases jusqu'au dernier chiffre.

## Contenu

- `analyse.py` : le script complet.
- `RAPPORT.md` : les chiffres et les décisions, phase par phase.

## Dépendances

`pandas`, `numpy`, `scikit-learn`.
